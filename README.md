# LoveConect (Android)

Aplicativo mobile desenvolvido em **Kotlin** no **Android Studio**, com foco em **autenticação**, **navegação estruturada** e **arquitetura organizada**.

## ✨ Funcionalidades
- Login (SMS / E-mail) *(conforme implementação atual)*
- Cadastro de usuário
- Navegação por rotas (NavHost / Compose)
- Telas organizadas por módulos

## 🧱 Tecnologias
- Kotlin
- Android Studio
- Jetpack Compose
- Navigation Compose

## ▶️ Como rodar o projeto
1. Clone o repositório
2. Abra no Android Studio
3. Aguarde o Gradle sincronizar
4. Execute em um emulador ou dispositivo físico
